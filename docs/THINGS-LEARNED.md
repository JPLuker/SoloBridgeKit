# Things learned

## New project groundwork (2026-11-11)

**Situation:** A D&D Beyond-like fan companion was requested before the commercial source PDFs were attached.

**Lesson:** Build rule-independent storage, navigation, reader and mission features first. Explicitly label placeholder character fields and do not invent successes, stat ranges or random table results without verified source material.

**Keep:** File import is local-only; public source repository contains no copyrighted PDF text.
